Fire Battery Calculator Support

The Fire Battery Calculator is a professional engineering aid for calculating standby battery requirements for fire detection and fire alarm systems.

The application provides battery calculations, system records, charger-voltage testing information and PDF report generation.

The application is intended as an engineering calculation and record-keeping aid. Users should consult the current applicable standards, system design information and manufacturer documentation when determining compliance.

Intruder Battery Calculator Support

The Intruder Battery Calculator is a professional engineering aid for calculating standby battery requirements for intruder alarm and associated signalling systems.

The application provides battery calculations, system records, monitoring information and PDF report generation.

The application is intended as an engineering calculation and record-keeping aid. Users should consult the applicable standards, system design information and manufacturer documentation when determining compliance.
